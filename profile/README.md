<h1 align="center">Halcyon Frame</h1>

<p align="center"><em>A calm screen for the things you love. Local, quiet, yours.</em></p>

In Greek myth, the gods stilled the sea for seven days each winter so the halcyon, the kingfisher, could nest on
the waves. Halcyon Frame aims for that same calm: e-paper frames that show your photos and a few useful
glances, with no glow, no notifications, no cloud account and no subscription.

**Principles**

- **Local first.** Photos and settings stay on the frame's own card. No account, no cloud storage; the
  only internet use is optional automatic time and time-zone setup, and one switch turns it off.
- **Open.** Firmware, server and site are MIT-licensed and built in the open.
- **Calm by design.** Changes happen slowly and quietly; the frame never demands attention.
